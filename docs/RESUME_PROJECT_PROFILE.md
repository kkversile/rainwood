# Resume project profile — RainWood

**Current role:** Lead Technology & Product Development, Doview Holidays India Pvt Ltd / DVi Travel

RainWood is a hotel direct-booking and reservation application that demonstrates full-stack product ownership across the public booking experience, hotel inventory, pricing, reservations, payments, administration and operational integrations.

## Resume-aligned technology

- Next.js, React and TypeScript frontend
- NestJS REST API with Prisma and PostgreSQL
- JWT authentication, role guards, audit logging and secure refresh-token rotation
- Transactional availability and inventory holds, reservation/payment state machines and idempotent webhook handling
- AxisRooms integration boundary, durable outbox jobs, reconciliation, reports, health checks and Prometheus metrics
- Jest unit/service coverage and API E2E validation

## Resume-ready contribution summary

Designed and delivered a production-oriented hotel booking platform from frontend through backend and database layers. Implemented hotel discovery, date-based availability, occupancy and pricing rules, temporary inventory holds, reservation conversion, cancellation restoration, payment verification and role-based operations. Established modular NestJS services, Prisma data models, integration boundaries, auditability and automated validation to support maintainable release and production-support workflows.

## Scope note

This repository is the RainWood direct-booking application and uses PostgreSQL. It should be described separately from the DVi Travel Management System, whose operational travel workflows and MySQL deployment are documented as a distinct project on the resume.
